# Countdown Timer Challenge

A React-based countdown timer game where players race against the clock. Set your name, pick a difficulty level, and try to stop the timer as close to the target time as possible.

## Features

- **Player Name** – Set a custom player name
- **Multiple Difficulty Levels** – Easy (1s), Not Easy (5s), Getting Tough (10s), Pros Only (15s)
- **Result Modal** – Shows how close you were to the target time

## Tech Stack

- React 19
- Vite
- ESLint

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Scripts

| Command         | Description                  |
| --------------- | ---------------------------- |
| `npm run dev`   | Start Vite dev server        |
| `npm run build` | Build for production         |
| `npm run lint`  | Run ESLint                   |
| `npm run preview` | Preview production build   |
